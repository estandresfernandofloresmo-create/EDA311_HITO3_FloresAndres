EDA311_HITO3_FloresAndres - Sistema de Gestión Tienda de Flores

Este proyecto es una aplicación web desarrollada en PHP y MySQL para las tablas clientes pedidos que integra un crud y visualizacion 

## 1. Requisitos de Software
Servidor Web:** Apache (vía XAMPP, WAMP o Laragon).en este caso se uso dbeaver
el Lenguaje de Programación usado fue: PHP 
Base de Datos: MySQL / MariaDB.
Control de Versiones: Git.
